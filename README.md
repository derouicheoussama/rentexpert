> **RentExpert** — ERP de gestion de location de voitures pour l'Algérie :
> contrats, clients, flotte, GPS Traccar, paiements, licences Ed25519, multi-thèmes.
> Édité par **Derouiche Oussama — Infinity Coder** (Oran, Algérie).

## À propos de ce dépôt

Ce dépôt est le **canal officiel de distribution des mises à jour** de l'application
Windows RentExpert. L'application installée chez les clients interroge ce dépôt pour
vérifier et télécharger automatiquement les nouvelles versions.

- `control.json` — manifeste de version (numéro, empreinte, URL de téléchargement)
- [Releases](https://github.com/derouicheoussama/rentexpert/releases) — installateurs publiés

## Fonctionnalités de l'application

- Gestion complète des contrats de location et des clients
- Suivi de flotte avec géolocalisation GPS (Traccar)
- Licences Ed25519 vérifiées localement
- Facturation en dinars, impressions A4 personnalisables
- Fonctionne hors ligne — données locales
